# Geo-Explorer

O **Geo-Explorer** é um projeto desenvolvido no desafio da DIO para demonstrar:

- Leitura de arquivos JSON  
- Criação de comandos personalizados  
- Geração de desafios automáticos  
- Emissão de certificados fictícios  
- Organização de projeto em múltiplos arquivos Python  

---

## 📁 Estrutura do Projeto

Geo-explorer/
│
├── data/
│   └── trilhas.json
│
└── src/
├── trilha.py
├── desafio.py
├── certificado.py
├── main.py
├── teste.py
├── teste_desafio.py
└── teste_certificado.py

---

## ▶️ Como Executar

Para rodar o projeto:
python src/main.py

---

## 🧠 Funcionalidades

### ✔ Ver trilha  
Mostra os módulos de uma trilha específica (ex: Python iniciante).

### ✔ Gerar desafio  
Cria um desafio baseado em um módulo aleatório da trilha.

### ✔ Gerar certificado  
Gera um certificado fictício com todos os módulos concluídos.
